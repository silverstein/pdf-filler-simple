# PDF Tools v0.9.4: Shannon Remainder Reduced from 80 to 11

PDF Tools `v0.9.4` safely recovers 64 additional minus signs and five
additional commas from Shannon's 55-page *A Mathematical Theory of
Communication*. The named but unrecovered Type-3 census falls from 80
occurrences to 11 without guessing.

## What improved

The 64 minus signs now match one exact target glyph and two independently
identified companion glyphs from the same uniquely identified Computer Modern
math-symbol font. The five commas likewise match one exact target and the
already qualified period and slash companions.

Every recovery still requires the exact source character, official metric
family, target glyph image, two companion glyph images, raw-font link, and
complete page-wide operator/text binding. Companion-only symbols are evidence,
not replacement targets.

The final Shannon output changes exactly 69 characters: 64 replacement
characters become minus signs and five incorrect semicolons become commas. No
other output character changes.

## Honest limits

This is source-bound recovery for the named Shannon PDF, not general Type-3
decoding, OCR, or arbitrary formula reconstruction. The eleven alpha cases
remain unchanged because the source does not safely identify one placement for
each glyph. Visual PDF comparison remains deterministic evidence from the
supported local parser and renderer, not proof of semantic equivalence.
