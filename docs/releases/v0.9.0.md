# PDF Tools v0.9.0: Reliable Markdown Extraction and PDF Comparison

PDF Tools `v0.9.0` adds source-bound PDF comparison and substantially improves
deterministic Markdown conversion for difficult born-digital PDFs.

The extraction work was developed against Claude Shannon's 55-page 1948 paper,
*A Mathematical Theory of Communication*. It improves headings, reading order,
paragraph continuity, mathematical spacing, conservative table recovery,
qualified legacy Computer Modern Type-3 glyph recovery, and one narrowly
supported form of explicitly barred prose fraction. Every recovery fails closed
when its required source evidence is missing or ambiguous.

## Highlights

- Added `compare_pdfs`, which reports source-bound page, text, form, annotation,
  metadata, and rendered-page observations without inventing semantic intent.
- Added reusable PDF observation and comparison modules with typed coverage and
  explicit limits.
- Added a bounded layout representation and deterministic
  `convert_pdf_to_markdown` workflow with page identity, canonical coordinates,
  typed conversion gaps, and optional verified UTF-8 output.
- Improved document-title and section-heading recovery while rejecting equations,
  fragments, and malformed heading candidates.
- Improved narrowly supported paragraph continuity and prose/math spacing without
  unsafe line-end dehyphenation.
- Added conservative table recovery from complete recurring-column evidence,
  clean ruled grids, or one complete bounded solid-mask grid. Ambiguous and
  merged-cell topology remains reading-order text with a typed gap.
- Added exact recovery for qualified legacy Computer Modern Type-3 glyph groups.
  Unknown or ambiguous glyphs remain visible and are reported rather than guessed.
- Added a narrow source-backed recovery for the prose phrase `3 1/3` when the PDF
  contains an aligned numerator, denominator, and explicit matching fraction bar.
- Updated the MCP SDK and vulnerable transitive production dependencies. The root
  runtime and share package both report zero production advisories.
- Kept the distributable focused: first-party tests, private evaluation outputs,
  evidence records, and source PDFs are excluded from both release artifacts.

## Install

Claude Desktop users can download `pdf-toolkit-mcp.mcpb` from this release and
open it to install. Cursor and other local stdio MCP hosts can use
`pdf-toolkit-mcp.zip` or point their configuration at `server/index.js` in a
source checkout.

## Honest limits

PDF Tools does not perform OCR, decode every Type-3 font, reconstruct arbitrary
formulas, infer ambiguous merged tables, or promise paper-wide visual fidelity.
It performs conservative source-text transcription and reports unsupported or
incomplete coverage as typed gaps. Filesystem work remains local, but content
returned through MCP may be processed under the selected host or model
provider's data terms.
