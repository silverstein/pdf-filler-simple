# PDF Tools v0.9.2: Safer Comparison and Exact Shannon Alphas

PDF Tools `v0.9.2` improves two difficult cases without broadening its claims:
it restores 49 source-supported alpha symbols in Claude Shannon's 55-page
paper, *A Mathematical Theory of Communication*, and prevents a wholly
off-page comparison exclusion from hiding a real change at a page edge.

## What improved

The Shannon recovery uses the PDF's exact text operators to distinguish an
alpha from an ordinary-looking collapsed space. A recovery is allowed only
when one qualified source control has one source slot, its visible neighbors
already belong to the same reconstructed line, and its calculated position
falls inside that line. Three cross-line cases, seven empty end-of-line slots,
one bundled control run, and one unqualified variant remain unchanged.

The comparison fix rejects malformed, degenerate, extreme, and wholly
off-page exclusion rectangles before the one-pixel visual padding is applied.
Partially intersecting rectangles still mask their visible portion, while
unrelated edge changes remain reportable.

## Shannon evaluation

Three fresh runs produced byte-identical Markdown with SHA-256
`2e7e4fb71d0ea116a352eb1aa1ed1b06c089969643073394d82e23eb5f6ffee3`.
The output contains exactly 49 recovered alpha symbols, 498 replacement
characters, and all 68 explicit gaps. The current sampled structural scores
remain unchanged:

| Metric | PDF Tools | PDF Inspector |
| --- | ---: | ---: |
| Qualified headings | 14/14 | 13/14 |
| Reading-order anchors | 24/24 | 19/24 |
| Paragraph-continuity samples | 3/4 | 1/4 |
| Equation-token samples | 4/4 | 1/4 |
| Footnote anchors | 4/4 | 4/4 |
| Qualifying table topology | yes | no |
| Equation-like false headings | 0 | 28 |

These are sampled anchors for one public document, not a general benchmark or
paper-wide mathematical-fidelity claim.

## Honest limits

The Shannon census now strictly recovers 1,160 of 1,240 officially named
Type-3 occurrences. The 80 unresolved occurrences remain unchanged: 64 minus
symbols without two qualified companion glyphs, 11 alpha cases that fail the
source-alignment rules above, and 5 commas without two qualified companion
glyphs. PDF Tools still does not perform OCR, decode every Type-3 font,
reconstruct arbitrary formulas, or infer ambiguous merged tables.

## Install

Claude Desktop users can download and open `pdf-toolkit-mcp.mcpb` from the
release assets. Cursor and other local stdio MCP hosts can use
`pdf-toolkit-mcp.zip` or the checked-out `server/index.js`.

Final release artifact identities and installed-copy evidence are recorded
after the merged release is built, downloaded again, installed, and verified.
